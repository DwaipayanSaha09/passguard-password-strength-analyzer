Security Best Practices
Click to expand — 8 essential tips
📏
Use 12+ characters
Every extra character multiplies crack time exponentially. 16+ is ideal for sensitive accounts.
🚫
Avoid common passwords
Words like "password", "123456", or your name are checked first in any dictionary attack.
🔑
Enable MFA everywhere
Multi-factor authentication blocks 99.9% of automated attacks even if your password leaks.
🗄️
Use a password manager
Tools like Bitwarden or 1Password generate and store unique passwords for every site securely.
🔄
Never reuse passwords
One breached site exposes all accounts if you reuse credentials. Each account needs a unique password.
🎲
Mix character types
Combine uppercase, lowercase, numbers, and symbols. Variety dramatically increases entropy.
📧
Check breach databases
Visit haveibeenpwned.com regularly to see if your email or passwords have appeared in known data breaches.
🕐
Rotate sensitive passwords
Change passwords for banking and email every 6–12 months, or immediately after any suspected breach.

About PassGuard

v2.0 · Built by Dwaipayan Saha

The Project

PassGuard is a personal cybersecurity project focused on helping users understand and improve their password hygiene through real-time analysis, entropy calculations, and estimated crack times.

How It Works

Passwords are scored across 9 security checks covering length, character variety, repetition patterns, and common password detection. Entropy is calculated based on charset size, and crack time is estimated at 10 billion guesses per second — representative of modern GPU attacks.

Features

Real-time analysis · Password generator (12/16/20 chars) · One-click copy · Dark/Light theme · Security tips panel · Terms & Privacy.

Built With

Python · Flask · Vanilla JavaScript · HTML/CSS — no frameworks, no trackers, no data collection.
