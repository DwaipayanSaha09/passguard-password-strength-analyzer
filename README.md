# PassGuard

A modern cybersecurity-focused password strength analyzer built with Python and Flask.

PassGuard helps users evaluate password security using entropy calculations, crack-time estimation, common-password detection, and multiple security validation checks.

## Features

* Real-time password strength analysis
* Password entropy calculation
* Estimated crack-time prediction
* Common password detection
* Security checklist validation
* Modern responsive UI
* Visual strength meter
* Cybersecurity-focused recommendations

## Tech Stack

* Python
* Flask
* HTML
* CSS
* JavaScript

## Installation

Clone the repository:

```bash
git clone https://github.com/DwaipayanSaha09/passguard-password-strength-analyzer.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```

## Security Checks

PassGuard evaluates:

* Password length
* Uppercase letters
* Lowercase letters
* Numbers
* Special characters
* Password entropy
* Common password usage
* Repeated characters
* Password complexity
