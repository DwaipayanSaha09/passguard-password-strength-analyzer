# PassGuard - Password Strength Analyzer

A modern cybersecurity-focused password strength analyzer built with Python, Flask, HTML, CSS, and JavaScript.

PassGuard helps users evaluate password security using entropy calculations, password crack-time estimation, common-password detection, password generation, and multiple security validation checks.

## Live Demo

https://passguard-password-strength-analyzer.onrender.com

## Features

### Password Security Analysis

* Real-time password strength analysis
* Entropy calculation
* Password crack-time estimation
* Security score evaluation
* Visual strength meter

### Security Validation Checks

* Minimum length validation
* Uppercase letter detection
* Lowercase letter detection
* Number detection
* Special character detection
* Repeated character detection
* Common password detection
* Space validation

### Password Utilities

* Secure password generator
* Copy password functionality
* Security recommendations
* Interactive user feedback

### User Interface

* Modern cybersecurity-themed UI
* Responsive design
* Real-time updates
* Interactive visual indicators

## Installation

Clone the repository:

```bash
git clone https://github.com/DwaipayanSaha09/passguard-password-strength-analyzer.git
```

Navigate to the project:

```bash
cd passguard-password-strength-analyzer
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python passguard.py
```

Open:

```text
http://127.0.0.1:5000
```
